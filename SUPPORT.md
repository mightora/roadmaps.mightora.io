# Support

Mightora Roadmaps is a free, community-maintained tool without a guaranteed support service.

- [User guide](https://roadmaps.mightora.io/guide.html): learn how to use the editor, dependencies, exports and sharing.
- [Report a bug](https://github.com/mightora/roadmaps.mightora.io/issues/new?template=bug_report.yml): include reproducible steps and your browser details, but not private roadmap content.
- [Suggest a feature](https://github.com/mightora/roadmaps.mightora.io/issues/new?template=feature_request.yml): describe the problem and desired outcome.
- [Contribute](CONTRIBUTING.md): help with code, documentation or sector examples.
- [Security policy](SECURITY.md): privately report vulnerabilities; never disclose them in a public issue.

Please search existing issues before opening a new one. There is no guaranteed response time.
