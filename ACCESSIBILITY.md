# Accessibility

We want Mightora Roadmaps to be usable with keyboards, assistive technologies and a range of screen sizes. Our design target is **WCAG 2.2 AA**, but **we have not commissioned an independent accessibility audit and do not claim conformance**.

The editor uses semantic headings, labelled controls and visible focus styles in many places. Areas that merit further testing include complex roadmap grids, keyboard navigation, dialogs, colour contrast, zoom, and screen-reader announcements.

Please [report an accessibility problem](https://github.com/mightora/roadmaps.mightora.io/issues/new?template=bug_report.yml) with the browser, assistive technology if relevant, steps to reproduce and the expected behaviour. Avoid attaching personal or confidential information.

Contributors should test keyboard-only workflows, 200% zoom, reduced motion preferences where applicable, and clear labels/error messages. See [CONTRIBUTING.md](CONTRIBUTING.md).
