# Project governance

Mightora Roadmaps is a community-oriented project maintained under the [Mightora GitHub organisation](https://github.com/mightora). The current repository maintainers make final decisions on merges, releases and the project direction. This is not yet a formal foundation or elected governance structure.

## How decisions are made

- **Ideas:** discuss significant changes in [feature-request issues](https://github.com/mightora/roadmaps.mightora.io/issues/new?template=feature_request.yml).
- **Contributions:** submit pull requests. Public review, automated checks and clear explanations are preferred.
- **Maintenance:** maintainers prioritise correctness, accessibility, user privacy, simplicity and compatibility with existing roadmap files.
- **Disagreements:** explain trade-offs respectfully and document important decisions in issues or pull requests.
- **Security:** report privately using [SECURITY.md](SECURITY.md), rather than a public issue.

Contributions are welcome, but submission does not guarantee acceptance or a response within a set period. Maintainers may close requests that are out of scope or unsustainable. Changes to governance should be proposed publicly.

## Releases and transparency

The repository history and GitHub Actions logs are public. The `main` branch is deployed to GitHub Pages after validation. The status badges reflect automated workflow results only; they do not constitute independent certification.
