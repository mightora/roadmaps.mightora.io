# Community code of conduct

Mightora Roadmaps welcomes contributors from every background and experience level. Our shared aim is to build a useful, accessible, respectful open-source tool.

## Expected behaviour

- Be welcoming, constructive and considerate.
- Assume good intent, but accept feedback when something causes harm.
- Focus criticism on ideas and code, not people.
- Help newcomers find documentation, context and approachable tasks.
- Respect privacy, intellectual property and attribution.

## Unacceptable behaviour

Harassment, discrimination, threats, bullying, deliberate disruption, doxxing, unwanted sexual attention and posting others' private information are not acceptable.

## Where this applies

These expectations apply in issues, pull requests, code review, discussions and other spaces used to represent the project.

## Reporting and enforcement

For a non-sensitive project concern, contact the maintainers in a public issue. For personal or sensitive conduct concerns, contact a maintainer privately using a contact route listed on their GitHub profile; do not post the details publicly. GitHub's own [abuse reporting](https://github.com/contact/report-abuse) is also available for conduct on GitHub.

Maintainers will consider reports fairly, limit unnecessary sharing of sensitive details and may edit or remove content, close threads, or restrict participation. We cannot promise specific response times. Maintainers are also expected to follow this policy.
